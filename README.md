# זיכרון ארוך טווח — אתר לימוד אישי

אתר שרץ במחשב ועוזר לשמר ידע לאורך זמן. כל בוקר הוא מציג סשן קצר (עד כ־15 דקות) של שאלות על יחידות ידע שהגיע מועד החזרה שלהן, מסביר למה כל שאלה הופיעה ומאיזה מקור היא באה, ומעדכן את מועד החזרה הבא לפי התשובה.

הכול מקומי: מסד נתונים SQLite בתיקייה `data/`, בלי ענן ובלי חשבון. אחרי ההתקנה המערכת עובדת גם בלי אינטרנט.

התוכנית המקורית נמצאת ב־[docs/spec.he.md](docs/spec.he.md).

## הפעלה

צריך Node.js בגרסה 22.18 ומעלה (מומלץ ה־LTS הנוכחי מ־nodejs.org).

- **הדרך הפשוטה (Windows):** לחיצה כפולה על `Start.cmd`. בפעם הראשונה הוא מתקין תלויות ובונה את הממשק, ואחר כך פותח את הדפדפן בכתובת http://localhost:4317.
- **משורת הפקודה:**

```bash
npm install
```

```bash
npm run build
```

```bash
npm start
```

השרת מאזין רק ל־127.0.0.1 — אי אפשר לגשת אליו ממחשב אחר.

### לנסות על נתוני דוגמה

```bash
npm run seed:demo -- --reset
```

```bash
npm run demo
```

זה בונה קורס הדגמה ("ביולוגיה של התא") עם שלושה שבועות של היסטוריה מדומה — כולל ימים שדולגו, רמזים, טעויות, סתירה בין מקורות והצעת AI שממתינה לאישור — בתיקייה נפרדת `data-demo/`, ומריץ אותו בכתובת http://localhost:4318. הנתונים האמיתיים ב־`data/` לא נגעים.

## שימוש יומיומי

1. **אחרי שיעור** — ב"נושאים" מוסיפים שיעור (תאריך + אילו נושאים נלמדו) ויחידות ידע עם שאלות, או מייבאים חומר ב"ייבוא".
2. **כל בוקר** — "היום": עונים לפני שרואים את התשובה, מסמנים מה נכלל בתשובה, ומדרגים (שגוי / חלקי / נכון / קל מאוד). מקשים: Ctrl+Enter להצגת התשובה, 1–4 לדירוג, H לרמז, Enter להמשך.
3. **בערב** — "היום" מציג כבר את מה שמתוכנן למחר.
4. **מדי פעם** — "בדיקה ואישור" להצעות שממתינות, ו"התקדמות" כדי לראות מה נשאר בזיכרון אחרי מרווחים ארוכים.

## איך התזמון עובד

התזמון שייך ליחידת ידע, לא לקורס. המנוע פשוט, דטרמיניסטי ומסביר כל החלטה:

- **לוח המרווחים:** יום → 3 ימים → שבוע → שבועיים → חודש → חודשיים → 4 חודשים. החזרה הראשונה היא ביום הלמידה. (המרווחים הם בין חזרה לחזרה; אפשר לשנות בהגדרות.)
- **נכון** מתקדם שלב. **קל מאוד** מתקדם שני שלבים. **חלקי** נשאר באותו מרווח.
- **שגוי** חוזר מחר ויורד שני שלבים, ושאלת תיקון קצרה מופיעה בסוף אותו סשן (בלי לשנות את התזמון).
- **רמז** הופך הצלחה לחלקית.
- **"ניסוח חלופי תקין"** נספר כנכון; **"השאלה לא ברורה"** לא נספר כלל — השאלה עוברת לבדיקה.
- **מצב תיקון:** 2 כישלונות מתוך 4 הניסיונות האחרונים → המרווח מוגבל לשבוע עד 2 הצלחות רצופות בלי רמז, ובעמוד היחידה מופיעה הצעה לחזור לחומר המקור.

**סדר העדיפויות בסשן:** נכשלו לאחרונה ← באיחור ← חומר מרכזי או מבחן בשבועיים הקרובים ← ידע בסיס ← לא נבדקו זמן רב ← שאלות יישום ואינטגרציה. מה שלא נכנס בתקציב (15 דקות / 12 שאלות, לפי זמן המענה האמיתי שנמדד) מוצג כ"נדחה" עם הסיבה ועובר למחר. שום חזרה לא נעלמת: גם ימים שבהם האתר לא נפתח בכלל נספרים כחזרות שפוספסו.

## מקורות ואמינות

- **ייבוא:** PDF, PowerPoint, Word, Excel, TXT/MD/CSV — מתיקיית הקורס (סריקה), בהעלאה, או כמקור ידני (שיעור, תאריך, קישור). הטקסט נשמר עם מספרי עמודים או שקופיות, ומתגלות כפילויות. קובצי המקור רק נקראים — לעולם לא נכתבים.
- **Quizlet:** ב"ייבוא" אפשר להדביק ייצוא של Quizlet (מונח ⇥ הגדרה בכל שורה).
- **לכל שאלה מקור:** חומר רשמי / מבחן קודם / נוצרה מתוך מקור / הרחבה חיצונית / דורש בדיקה. שאלה ש"דורשת בדיקה" מוצגת עם אזהרה ולא כעובדה.
- **סתירה בין מקורות** מוציאה את השאלות הרלוונטיות מהחזרות עד שמיישבים אותה.
- **AI רק מציע.** ספק הדמה (כללים, בלי מודל) או מודל מקומי דרך Ollama. כל הצעה עוברת בדיקה אוטומטית — הציטוט חייב להופיע במקור מילה במילה — ונכנסת לחזרות רק אחרי אישור ידני עם "בדקתי מול המקור". ה־AI לא מחשב תאריכים ולא מאשר כלום.

## גיבוי, ביטול ושחזור

- כל פעולה (אישור, עריכה, איחוד נושאים, חזרה, שחזור) נרשמת ב**יומן הפעולות** (הגדרות) עם המצב לפני ואחרי, ואפשר לבטל אותה משם.
- **גיבוי אוטומטי** של מסד הנתונים פעם ביום לימוד (`data/backups/`, נשמרים 30 האחרונים), ו**ייצוא JSON מלא** פעם בשבוע (`data/exports/`).
- **שחזור** מגיבוי או מקובץ JSON — בהגדרות. לפני כל שחזור נשמר גיבוי "לפני שחזור", כך ששחזור תמיד הפיך.
- **Excel** הוא דוח בלבד (הגדרות › ייצוא), לא מקור האמת.

## מצב השלבים בתוכנית

| שלב | מצב |
|---|---|
| 1 — בסיס בלי AI | בנוי: מסד נתונים, קורסים/נושאים/שיעורים/יחידות/שאלות, תזמון, דף היום, תיעוד תוצאות, גיבוי |
| 2 — בדיקת שימוש | בנוי: קורס הדגמה עם היסטוריה, הזזת שעון לבדיקה (הגדרות › מצב בדיקה), בדיקות אוטומטיות לעומס, ימים שפוספסו, רמזים ושחזור |
| 3 — ייבוא חומר | בנוי: חילוץ PDF/PPTX/DOCX/XLSX עם עמודים/שקופיות, כפילויות, מסך אישור |
| 4 — מפת נושאים ושאלות | בנוי: הצעות מסילבוס, קישור לשיעורים, סתירות, אישור/עריכה/פסילה |
| 5 — AI מקומי | בנוי: ספק דמה + ספק Ollama. ספק Ollama נבדק רק מול תשובות מדומות — עוד לא מול מודל אמיתי |
| 6 — פיילוט בקורס אמיתי | לביצוע: קורס אחד, אישור ידני של המפה והשאלות, חודש שימוש |
| 7 — הרחבה | אחרי הפיילוט |

## לפיתוח

- `npm test` — בדיקות (תזמון, סדר עדיפויות, שירותי השרת מול SQLite אמיתי, חילוץ קבצים, שכבת ה־AI).
- `npm run typecheck` — TypeScript לשרת ולממשק.
- `npm run dev:server` ו־`npm run dev:web` — פיתוח עם טעינה מחדש (הממשק ב־5173 מפנה את ה־API ל־4317).
- מבנה: `shared/` (מנוע התזמון, סדר העדיפויות ובחירת השאלה — טהורים וזהים בשרת ובממשק), `server/` (Express + `node:sqlite`, רץ ישירות מ־TypeScript בלי שלב בנייה), `web/` (React + Vite, עברית מימין לשמאל).
- משתני סביבה: `MEMORY_DATA_DIR` (תיקיית הנתונים), `MEMORY_PORT` (ברירת מחדל 4317).
